# UI 设计样稿

这里保存历史单需求交互样稿，不作为生产前端入口或全项目 current。新的 UI 需求使用仓库根目录的 [Design 工程](../../../design/README.md)，在当前完整页面内迭代。

## 历史对话搜索

- [打开 HTML 样稿](conversation-search.prototype.html)
- [需求规格](../2026-09-05-conversation-search.md)

直接用 Chrome 打开 HTML 即可，无需安装依赖、启动应用或登录。样式、SVG、脚本与 mock 数据全部内置，不请求外部字体、接口或图片。刷新页面会重置本次操作。

### 建议的检查顺序

1. 默认搜索“数据库”：检查正文命中、仅标题命中和长标题的排列，点击第一条看定位标黄。
2. 使用右侧场景选择器查看最近对话、无结果、加载和失败状态。固定加载场景通过“完成请求”结束，失败场景通过产品内“重试”恢复。
3. 查看重复词、代码及长引用场景。按 Enter 打开首条结果；只有选定的命中文字标黄，长引用会临时展开。点击“重播定位标黄”重复观察。
4. 查看加载更多失败场景，滚到结果底部触发失败，再重试；已加载的结果应保留。
5. 查看流式场景，搜索并定位到历史回复；底部模拟文字继续增长，阅读位置不被拉走。
6. 顶部切换移动端，检查全屏搜索、日期与截断；收起场景面板可单独查看产品界面。真实窄屏默认收起面板，顶部可再次打开。

输入框可以自由搜索全部 46 段 mock 会话，不必只使用预设关键词。支持 ↑↓、Enter、Escape、清除、关闭重开，以及当前页面内的查询/列表位置恢复。草稿在 mock 会话之间保存在内存中。

### 样稿边界

- 当前版本已被需求规格采用，仅供本需求的搜索 UI 对齐；业务规则仍以需求规格为准。发生 UI 冲突时，以实施时的前端设计规范、现有 token 和共享组件为准，不为还原样稿改动全局设计系统。
- 顶部工具栏、场景面板、设备预览、状态读数、模拟请求与重播按钮，以及一次性搭建的侧栏外壳、账户区、聊天区、输入框和周边操作均不作为生产 UI 参考。侧栏只参考本需求新增的搜索入口，其余部分保留现有前端设计。
- 15 个场景是设计检查入口，不是产品的分类标签；场景面板中的中文说明及状态读数不进入正式产品。
- 全部界面文案与可访问标签使用中文；品牌名、技术名称与代码原文保留原样。
- 搜索入口紧接“新建对话”下方：展开侧栏与移动抽屉为“新建对话 → 搜索对话 → 最近对话列表”；桌面 rail 为“新建对话图标 → 搜索放大镜 → 最近对话图标”。
- 桌面搜索卡片以整个浏览器视口水平居中，垂直方向比几何中心上移自身高度的 10%（默认 46px），参考 ChatGPT 截图位置，不受顶部设计工具栏和侧栏影响；移动预览仍在模拟设备内全屏展示。
- 搜索弹窗不添加全局变暗或模糊遮罩，保留卡片阴影及点击外部关闭。
- 无结果及失败提示整体居中于空白结果区；结果气泡复用项目 rail 图标（20px），仅“点击后结果失效”提示沿用项目 error alert，滚动条滑块与结果悬停背景同色。
- 使用简化的 Piko 宿主侧栏、消息区和 Composer，没有复制整个 React 工程；分享、上传和发送不在样稿实现范围内。
- 正文使用预设富文本和代码样式，不包含完整 Markdown、公式解析器。搜索匹配和高亮是真实的本地交互，但不证明生产搜索索引、权限、请求并发和性能已经实现。
- 日期以固定 mock 时间为准；全部数据均为示例，没有读取真实账户内容。
- 手机尺寸预览用于响应式对齐，不能代替 iOS/Android 真机软键盘、浏览器动态工具栏与辅助功能验收。
- 场景面板位于产品视口之外，刻意允许在搜索弹窗打开时操作。正式产品弹窗不包含这些外部控件。

### 本版验证记录

2026-09-05 使用 agent-browser 的真实 Chromium 检查：

- 1440×900 桌面、390×844 窄屏及桌面内 390px 移动预览，无页面横向溢出。
- 输入过滤、Enter 打开、重复词跨字重节点标记、代码内 `pool_size` 标记、长引用展开。
- 标黄时颜色为 `rgb(255, 240, 179)`；保持、淡出和移除的过程可观察，采样期间目标文字位置不变。
- 搜索失败重试恢复；分页从 30 条恢复到完整 37 条“方案”结果；失效场景不标记其他内容。
- 流式 mock 在采样期间由 4 个字符增长到 12 个字符，定位后的滚动位置保持 725px。

本轮界面修订已复查桌面与 390px 窄屏：空状态提示中心与空白结果区中心重合（误差小于 1px），“点击后结果失效”的 error alert 颜色与项目 token 一致，结果气泡为 20px 且路径与 rail 相同，滚动条与悬停色均为 `rgb(237, 237, 237)`。搜索及分页重试可恢复结果。

这些是独立样稿的检查记录，不替代需求规格中的生产验收。样稿没有修改生产代码、依赖或数据库。

后续评审修正：搜索失败恢复灰色图标、文字和重试按钮，加载更多失败恢复普通文字和重试按钮，复制失败恢复普通浮动提示；仅点击后结果失效保留失败 alert 样式。空状态居中与其他界面调整保持不变。
