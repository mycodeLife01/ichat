# 确认注销（软停用 + 全凭证吊销）

Type: feature

Status: completed

Blocked by: 05

## What to build

用户点击注销确认链接完成注销：账户立即停用（软注销——停用不等于数据删除，见 CONTEXT.md「注销」「停用」），全部凭证吊销。注销流程至此端到端可演示：发起 → 收信 → 确认 → 账户不可访问。同时补上申请重置对已停用账户静默不发信的最后一环端到端验证。

## Acceptance criteria

- [ ] 有效令牌：账户置停用，返回命令状态响应；此后 login、refresh、取当前用户全部被拒。
- [ ] 确认成功吊销该用户全部 refresh token 及**所有用途**的 active 认证令牌（含挂起的验证/重置令牌）。
- [ ] 数据保留：该用户的会话与消息在数据库中原样存在（软注销语义）。
- [ ] 过期、已使用、已撤销、格式非法的令牌分别得到明确失败，账户状态不变。
- [ ] 限流按 verify 模式：IP 限流，Redis 故障 fail-open。
- [ ] 端到端断言：已停用账户的邮箱申请密码重置，响应与成功场景一致且不发信、不签发令牌。
- [ ] HTTP API 层测试覆盖上述全部外部行为。
