# 生产化方案 A UserMenu 与退出登录

Type: feature

Status: completed

Blocked by: None

## What to build

把已确认的方案 A「渐进浮层」重写为生产组件：侧栏个人区域 hover 时切换背景，点击打开紧凑 UserMenu；菜单顶部只展示头像、昵称（不可用时回退用户名）和邮箱，不可点击。首个完整业务路径是退出登录——打开独立居中确认 Card，展示头像、名称、邮箱和简短影响提示，确认后调用现有登出编排，取消则无副作用返回。

本 ticket 吸收原型中已经确认的布局决策，删除 B/C 方案、原型切换器、开发查询参数入口和原型启动命令，不直接把 throwaway 组件原样提升为生产代码。

## Acceptance criteria

- [x] 桌面和移动端侧栏个人区域均可打开/关闭 UserMenu；hover、外部点击和 Escape 行为明确且不会干扰会话交互。
- [x] 菜单顶部用户信息是纯展示元素，不具备按钮语义或点击行为。
- [x] 退出登录确认 Card 展示头像或首字母回退、名称和邮箱，使用简短提示、主退出按钮与取消按钮。
- [x] 确认退出复用现有 best-effort 登出编排：即使服务端登出失败，也会中止运行流、清除本地凭证和私有状态并回到登录页。
- [x] Card 具备正确的对话框语义、焦点关闭路径和窄屏适配。
- [x] 组件测试从用户可见行为覆盖菜单开关、静态用户信息、取消与确认退出；现有侧栏和认证退出测试保持通过。
- [x] 原型专用 B/C 方案、切换器、启动命令和开发入口已清理，生产构建不包含原型文案。
