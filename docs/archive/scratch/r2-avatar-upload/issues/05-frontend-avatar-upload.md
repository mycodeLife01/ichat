# 前端裁剪、直传、轮询与头像同步

Type: task

Status: completed

Blocked by: 02, 03

## What to build

把账号卡片现有的本地头像预览升级为完整上传流程：选择原图、客户端校验、正方形裁剪、生成固定 WebP 中间 Blob、创建会话、R2 PUT、确认、轮询和全局用户状态更新。

真实头像只替换现有个人中心相关头像，不改变消息列表。没有头像或资源加载失败时回退为昵称首字母。用户不能单独移除头像。

## Acceptance criteria

- [x] 文件选择只接受 JPEG、PNG、静态 WebP，并在浏览器侧执行 10 MiB、2000 万像素、最长边 8192、最小 128×128 校验。
- [x] 不支持格式、动画、超限、解码失败都有明确且可访问的提示。
- [x] 正方形裁剪支持拖动、缩放、触屏操作、键盘可达控件和圆形实际效果预览。
- [x] 裁剪依赖被封装在项目组件后；业务组件不直接散布第三方 API。
- [x] 浏览器生成固定 1024×1024、质量 90、保留透明通道、最大 2 MiB 的静态 WebP；原图不上传。
- [x] Blob 生成后才创建上传会话；按后端返回的签名头 PUT 到 R2，并正确读取 ETag。
- [x] 确认后显示 queued/processing 状态并轮询；关闭卡片不取消已提交任务。
- [x] 成功后统一更新应用用户状态，使侧栏入口、UserMenu、账号卡片和退出确认框立即显示新头像。
- [x] 替换处理期间继续显示旧头像；首次上传显示字母回退；失败时当前头像不变。
- [x] 图片加载失败自动回退到昵称首字母，不形成重复请求或错误循环。
- [x] 未验证邮箱用户被引导先验证；429、Redis/R2 故障、过期会话和最终处理失败映射为明确提示。
- [x] 未确认的裁剪不跨刷新恢复；已提交任务刷新后可通过当前用户信息或状态查询观察最终结果。
- [x] 不提供移除头像按钮或 DELETE 调用，不向消息列表和公开分享页新增头像。
- [x] React 集成测试通过可访问角色覆盖选择、裁剪、上传、轮询、成功、失败、限流和多处同步，不断言裁剪库内部实现。
