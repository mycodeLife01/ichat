# 建立视觉模型与 ImageBlock 合同

## 目标

建立 provider 中立的图像内容合同和显式模型能力目录，使后续视觉 Run 能够记录模型实际所见图片，同时让未知或未验证模型默认不具备图片能力。

## 交付范围

1. 模型目录支持显式视觉白名单与正数图片 token 预留；空值、重复、非 OpenAI 子集和无效预留均导致 API 与 Worker 启动失败。
2. capabilities 在每个模型条目声明图片输入能力，并移除错误表达全局能力的文件级字段。
3. 新增包含文件身份、安全文件名、preview 媒体类型、哈希、尺寸、处理版本和 warning 的图像块；禁止保存字节、存储位置或临时 URL。
4. transcript 对图像块执行严格序列化与反序列化；未知类型、缺字段和不一致数据显式失败。
5. DeepSeek adapter 对任何越过业务层的图像块 fail-closed；应用错误 envelope 支持可选稳定 machine code。

## 验收

- [x] 合法视觉白名单只为明确配置的模型公开图片能力，未知模型默认关闭。
- [x] 所有非法配置组合均在进程启动时失败，而不是在首次 Run 时暴露。
- [x] 图像块可以无损严格往返 transcript，且持久化结果不含 URL、对象键或图片字节。
- [x] DeepSeek 收到图像块时不会发起 provider 请求。
- [x] 现有文字、文档、工具和附件提示块合同保持兼容。

## 非目标

- 本票不实现图片解析签名，也不提供可用的端到端 GPT 图片问答。
