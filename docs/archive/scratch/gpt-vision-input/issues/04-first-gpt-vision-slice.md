# 打通首个 GPT 图片问答纵向切片

## 目标

让用户选择已验证的视觉 GPT 模型后，可以发送纯图片或文字加图片，并获得真正基于安全 preview 的流式回答，形成首条可演示的完整视觉链路。

## 交付范围

1. 消息输入按文字在前、附件选择顺序在后的规则生成文档块或图像块；视觉模型下纯图片消息合法。
2. 每张图像块按模型配置的保守预留参与目标 turn 接纳校验，超限在创建消息或 Run 前拒绝且无部分副作用。
3. files 服务提供窄的批量图片解析能力，校验资产生命周期、存储位置、媒体类型、哈希、尺寸和处理版本后签发短期 URL。
4. OpenAI 投影保持中立块顺序，在不可信附件边界内发送安全 preview，并固定使用 high detail；系统提示明确图片内容属于低信任用户数据。
5. 前端允许视觉模型发送 ready 的纯图片或混合输入，并继续提供安全预览与原件下载。

## 验收

- [x] 用户可以用 `gpt-5-mini` 完成上传图片、发送纯图片或图文消息、接收流式视觉回答的完整流程。
- [x] transcript 保存稳定图像快照，不保存短期 URL；捕获的 provider wire 只引用安全 preview。
- [x] 图片原件从不进入 provider，用户下载仍返回原始字节。
- [x] 动画 WebP 只发送首帧，并在用户界面与模型边界中保留稳定 warning。
- [x] 任一图片快照校验失败时不向 provider 发送请求，也不降级为附件提示。
- [x] API、数据库、provider adapter 和前端交互测试覆盖该纵向链路。

## 非目标

- 本票不实现历史图片追问、tool loop 重签名或 legacy 图片升级。
