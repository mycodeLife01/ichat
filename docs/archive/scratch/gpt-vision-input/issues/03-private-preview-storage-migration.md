# 隔离并迁移安全图片派生物

## 目标

把安全图片 preview 从附件原件所在的 canonical 私有存储迁入独立私有位置，使 LLM Worker 可以在凭证层只读取模型输入派生物，无法读取原件。

## 交付范围

1. 文件对象增加模型 preview 私有位置；新上传图片直接把安全 preview 写入该位置，原件与文档派生物保持原位置。
2. 用户 preview 读取按每行真实位置兼容迁移期双读，下载始终返回原件；文件删除补偿覆盖新位置。
3. backfill 按确定性对象身份执行复制、大小与哈希校验、事务切换和旧对象删除补偿，可在每个崩溃点幂等续跑。
4. 迁移期资产删除同时补偿旧位置和潜在新位置，不存在对象视为成功。
5. 建立 API preview 只读、LLM preview 只读和 file-worker 写入/删除三种隔离权限配置，并公开安全的剩余量与失败量统计。

## 验收

- [x] 新图片上传后，原件与安全 preview 位于预期隔离位置，预览和原件下载行为均正常。
- [x] LLM 读取角色无法读取 canonical 原件，API 读取角色无法写入 preview。
- [x] backfill 在复制前后、数据库切换前后和删除补偿前后的重复执行均不会产生错误状态或孤儿对象。
- [x] 生命周期回收、会话删除与账户停用路径都能清理新位置对象。
- [x] fake storage 自动化测试覆盖迁移、双删、404 幂等和统计结果。

## 非目标

- 本票不启用视觉白名单，也不调用 GPT。
