# 完成视觉发布门禁、遥测与运行手册

## 目标

把已实现的视觉能力包装成默认关闭、可观测、可验证和可快速回滚的发布单元，在真实资源验收前不对生产用户声明图片能力。

## 交付范围

1. 开发与生产编排明确隔离 preview API 读取、preview LLM 读取和 file-worker 写入凭据；LLM Worker 显式不持有 staging、canonical 原件和写入凭据。
2. API 与 Worker 在视觉白名单、图片预留和存储配置不一致时启动失败；白名单为空时既有图片仍可展示和下载。
3. 建立 resolver 成功率、失败分类、耗时、每次调用图片数、图片 usage、backfill 剩余量与失败量的安全指标和告警建议。
4. 日志审计覆盖全部错误路径，禁止 URL、bucket、对象键、文件名、哈希、图片内容和完整 provider 请求。
5. 更新中文部署、维护窗口、同版本发布、真实 R2/GPT 冒烟、灰度、回滚与故障排查文档。
6. 形成自动化发布门禁：全量后端与前端检查、开发和生产编排校验、backfill 查询以及白名单开启前置条件。

## 验收

- [x] 普通 CI 使用 fake adapters 即可完成，不需要生产 R2、ClamAV 或 GPT 凭据。
- [x] 编排检查证明各进程只接收角色所需配置，LLM Worker 无法读取附件原件。
- [x] 视觉白名单为空时新视觉流量关闭，已有 transcript、preview 和生命周期任务继续正常运行。
- [x] 仪表和日志只包含允许的内部身份、计数、耗时、稳定错误类别与汇总 usage。
- [x] 运行手册明确先关闭白名单再排空事实行的回滚顺序，不要求回迁 preview 或改写 transcript。
- [x] 全量自动化检查与编排配置检查通过。

## 非目标

- 本票不声称真实开发或生产资源已经完成权限、连通性、容量和模型效果验收。
