# 真实资源灰度并开启视觉能力

## 目标

在受控真实环境完成对象存储、凭据、迁移、GPT 视觉效果、可观测性和回滚验证，所有发布门禁通过后再向生产 capabilities 开放视觉模型。

## 交付范围

1. 创建并核对独立 preview bucket、精确 CORS、生命周期策略和五组最小权限凭据，使用容器实际注入值验证隔离而非只检查变量名。
2. 在维护窗口执行 schema 切换与同版本前后端发布，保持视觉白名单为空，并要求旧浏览器标签页刷新。
3. 运行 preview backfill 至剩余量和失败量均为零，验证迁移期删除、删除补偿和配额事实无异常积压。
4. 使用安全随机测试图完成纯图片识别、连续追问、URL 过期后重入、原件不可读和日志无敏感信息的真实 R2 + `gpt-5-mini` 冒烟。
5. 记录关键延迟、失败率和资源指标，完成关闭白名单的回滚演练后再开启生产视觉白名单。

## 验收

- [ ] API、LLM Worker 与 file-worker 的实际凭据权限符合最小权限矩阵，越权操作均失败。
- [ ] backfill 剩余量为零、失败量为零，旧位置删除补偿和新位置读取均完成验证。
- [ ] 真实视觉冒烟能读出随机标识、跨 turn 引用图片，并在旧 URL 过期后继续成功。
- [ ] R2 访问记录证明 LLM 角色只读取 preview bucket；应用日志不含任何禁止信息。
- [ ] 全量自动化检查、编排检查、关键指标观察和回滚演练均留下可审计结果。
- [ ] 只有上述条件全部满足后才开启视觉白名单；任一门禁失败均保持关闭。

## 非目标

- 本票不修改业务设计，不以临时放宽凭据、日志或安全校验换取上线。
