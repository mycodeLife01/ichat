# 让图片跨历史、工具循环与重试可靠重放

## 目标

让已经进入当前上下文的图片在连续追问、工具循环、provider 重试和用户长期离开后返回时继续可读，而不依赖旧的预签名 URL。

## 交付范围

1. 每次真正组装模型调用前，从裁剪后的完整 turn 中收集全部图像块，按文件身份批量查询并在单次调用内去重签名。
2. 后续模型调用、工具循环和 provider 重试都重新解析并签发 URL，投影时恢复原始块顺序。
3. 保留某个历史 turn 时保留其中全部文字、图片、文档和回答；图片预留与文档正文共同参与预算，目标 turn 永不裁剪。
4. 任一图片永久缺失或快照不匹配时整次调用以稳定类别失败；暂时存储或签名故障仅在 provider 尚未输出时进入既有重试边界。
5. 日志在失败和重试路径中只记录安全聚合信息，不记录 URL、bucket、对象键、文件名、图片哈希或完整请求。

## 验收

- [x] 用户无需重新附图即可连续询问历史图片，等待短期 URL 过期后仍能继续。
- [x] tool loop 的每次模型调用和 provider 重试都使用新许可，同一调用中的重复图片只签发一次。
- [x] 多图片比较保持用户原始顺序，不会因批量解析或去重改变语义。
- [x] 一张图片失败会阻止整次 provider 请求，不会产生部分图片或纯文字回答。
- [x] 目标 turn 超限在 Run 创建前拒绝，历史只按完整 turn 裁剪。
- [x] 安全日志测试证明所有禁止字段均未泄露。

## 非目标

- 本票不处理历史仅展示图片的显式升级流程。
