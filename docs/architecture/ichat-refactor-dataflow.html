iChat · Post-Refactor Architecture

重构后的 iChat：架构与核心数据流

三个交付把 agent 编排从 worker 中抽出为纯运行时，把实时流式从 PostgreSQL 迁到 Redis Stream，并统一后台任务模型。 核心原则一句话：PostgreSQL 是事实源，Redis 承担实时广播与唤醒， AgentRunner 是不碰 DB、不碰传输的纯编排内核。点击组件查看职责，或用右侧播放器逐步走一遍数据流。
