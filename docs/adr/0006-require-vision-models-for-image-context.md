# 图像上下文要求使用视觉模型

当前有效分支包含 `ImageBlock` 时，后续 Run 必须使用显式白名单声明的视觉模型；约束从当前消息与其 Run transcript 派生，不持久化会话模型或视觉标记，移除全部图片输入后约束自然解除。视觉功能上线前只有 `AttachmentNoticeBlock` 的旧图片历史保持不可变，用户只能从当前分支最早的此类消息明确编辑或重新生成来升级，新 Run 更新该消息的 `run_id` 并按既有分支规则归档后续消息，失败或取消不回退已经提交的新输入快照。该约束牺牲部分会话内模型切换自由，以避免模型在未获得图片时假装理解、历史被静默改写，以及更早 notice 与较晚 `ImageBlock` 形成无法选择模型的混合上下文。
