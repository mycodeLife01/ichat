# 发起并确认注销

Type: feature

Status: ready-for-agent

Blocked by: 02

## What to build

在账号 Card 中提供独立的“注销账号”子视图。用户必须重输当前密码才能发起注销确认邮件；发送成功后得到明确反馈但账户尚未停用。邮件中的公开确认链接由前端落地页消费，成功后账户进入既有软停用状态并清除本地会话。

## Acceptance criteria

- [ ] “注销账号”从账号概览进入危险操作子视图，文案明确区分“发送确认邮件”和“已完成注销”。
- [ ] 发起注销必须输入当前密码；提交态防重复，错误密码、冷却/限流和通用失败均提供明确反馈。
- [ ] 发送成功后提示用户检查当前邮箱，不提前清除会话或宣称账号已经注销。
- [ ] 公开确认落地页可在未登录状态读取邮件 token 并调用既有确认能力，覆盖加载、成功、无效/过期和重复使用状态。
- [ ] 确认成功后清除可能存在的本地认证会话并展示账号已停用结果，不自动恢复或物理删除数据。
- [ ] 组件/API/路由测试覆盖发起成功与失败、公开确认成功与失效，以及本地会话清理。
