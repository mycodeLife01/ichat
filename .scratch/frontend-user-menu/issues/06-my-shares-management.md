# 我的分享聚合管理

Type: feature

Status: ready-for-agent

Blocked by: 01

## What to build

在 UserMenu 中加入“我的分享”入口，展示当前用户跨全部会话创建的所有有效分享。现有管理接口只按单个会话列出分享，因此需要增加用户作用域的聚合查询；返回足够的会话标识、标题、token、创建和过期信息，使前端可以复制公开链接并通过现有撤销语义撤销指定分享。

## Acceptance criteria

- [ ] 经过认证的用户可以一次查询自己全部会话的有效分享；结果不包含已撤销、已过期或其他用户的分享。
- [ ] 每项包含前端展示与撤销所需的会话公开标识、会话标题、分享 token、创建时间和过期时间，不新增查看次数。
- [ ] 聚合结果顺序稳定且适合最近创建优先展示；不存在分享时返回空列表而非错误。
- [ ] “我的分享”Card 覆盖加载、空状态、错误和列表状态，并适配桌面与窄屏。
- [ ] 复制公开链接后使用现有全局 Toast 显示“链接已复制”。
- [ ] 撤销成功后立即从当前列表移除并使用现有全局 Toast 显示“已撤销分享”；失败时保留列表项并显示失败反馈。
- [ ] 后端 HTTP API 测试覆盖跨会话聚合、所有权隔离和有效性过滤；前端组件/API 测试覆盖加载、空态、复制、撤销成功与失败。
