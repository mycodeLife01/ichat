# 账号概览与邮箱验证

Type: feature

Status: ready-for-agent

Blocked by: 01

## What to build

在 UserMenu 中加入“账号”入口，打开方案 A 的账号概览 Card。用户可以查看头像、当前展示名称、邮箱和邮箱验证状态；头像和“选择图片”按钮都能打开文件选择，本期仅在浏览器内预览。未验证用户可从 Card 发送验证邮件，并获得与现有验证体系一致的冷却、成功和错误反馈。

## Acceptance criteria

- [ ] “账号”入口打开自适应大小的居中 Card，关闭后聊天上下文保持不变。
- [ ] 账号概览展示头像、展示名称、邮箱及图文垂直对齐的“已认证/未认证”状态。
- [ ] 点击头像或“选择图片”都可选择图片并立即本地预览；离开或刷新后不承诺保留，且不会调用上传接口。
- [ ] 未认证用户可调用既有重发验证邮件能力；提交态防重复，成功、冷却和失败均提供明确反馈。
- [ ] 已认证用户不显示发送验证邮件动作。
- [ ] 账号子项 hover 不切换背景色，键盘操作和可访问名称完整。
- [ ] 组件测试覆盖已认证/未认证、头像两种入口、重发成功与失败，以及 Card 开关行为。
