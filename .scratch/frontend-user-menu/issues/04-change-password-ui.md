# 已登录改密

Type: feature

Status: ready-for-agent

Blocked by: 02

## What to build

在账号 Card 中提供独立的“修改密码”子视图，让已登录用户提交当前密码和新密码，调用既有改密能力。改密成功会使全部会话凭证失效，因此前端应立即清除当前本地会话并回到登录页；失败时留在表单并显示可操作的错误信息。

## Acceptance criteria

- [ ] “修改密码”从账号概览进入独立子视图，可返回概览且不关闭整个 Card。
- [ ] 当前密码与新密码使用正确的密码输入和自动完成语义；新密码执行 8–128 字符客户端校验。
- [ ] 前端 API 客户端接入既有改密端点，提交期间禁止重复请求。
- [ ] 改密成功后中止运行流、清除本地认证会话和私有状态并返回登录页，符合后端全设备下线语义。
- [ ] 当前密码错误、限流和通用失败均显示明确反馈，不误清除当前表单或会话。
- [ ] 组件/API 测试覆盖成功退出、错误密码、限流及客户端校验。
