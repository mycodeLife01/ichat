# XLSX 安全文本提取

## 目标

复用已验证的 OOXML 安全容器 seam，支持 XLSX 可见工作表和单元格内容进入模型，同时
绝不执行或重新计算公式。

## 交付范围

1. XLSX 最大 20 MiB，并继承 100 MiB 解压总量、10,000 entries、路径穿越、压缩比、
   XXE、外部引用、加密与内部类型检查。
2. 最多提取 50 个可见工作表和合计 100,000 个实际非空单元格；排除隐藏工作表、隐藏行列、
   批注、文档属性、宏、嵌入对象和外部连接。
3. 派生文本保存稳定工作表名称、单元格地址、公式文本及文件内已有缓存值。不得执行公式、
   重新计算、访问外部连接或用本地环境补齐缓存。
4. 部分工作表可读时允许 ready 并生成 warning；没有任何可提取单元格时 rejected。全文
   按正常 DocumentBlock、128k 预算、transcript、下载和生命周期路径处理。
5. UI 显示 XLSX 卡片、工作表/单元格统计、warning 和原件下载，不增加电子表格阅读器。

## 验收

- golden tests 覆盖字符串、数值、日期、公式+缓存值、多工作表及稳定单元格地址输出。
- 隐藏 sheet/行列、comments、external links、宏和属性不会进入派生文本，测试期间无公式执行
  或外部网络访问。
- 覆盖 50 工作表、100,000 非空单元格边界、稀疏超大坐标、损坏、加密和 OOXML 攻击样例。
- 正常、部分可读、零语义内容和资源超限得到稳定 ready/rejected 状态与 warning/error code。
- XLSX 完成上传→ready→发送→provider→历史回放→下载；后端和前端全套检查通过。
