# 一步切换模型输入表示

## 目标

在已确认的短维护窗口内，把文件资产的单一“模型可消费”布尔值替换为文档、图像或空值三态表示，同时保持现有文档输入和仅展示图片行为不变，为视觉切片建立无歧义的数据合同。

## 交付范围

1. 数据库迁移新增并完整回填模型输入种类，验证所有既有资产后删除旧字段，不提供双写或旧客户端兼容层。
2. 文件处理、消息绑定、API 响应、前端类型与草稿恢复统一使用新表示；文档继续产生文档块，图片暂时继续产生附件提示块。
3. 对未知、缺失或与文件类别冲突的输入种类 fail-closed，避免迁移后把不可读文件错误送入模型。
4. 补充维护窗口、同版本发布和旧标签页必须刷新的操作约束。

## 验收

- [x] 迁移能把既有可消费文档、仅展示图片和不可消费文件准确映射为新三态，并在异常数据存在时拒绝完成收缩。
- [x] 上传、发送、编辑、重新生成、下载和草稿恢复的既有外部行为保持不变。
- [x] API 与前端不再暴露或依赖旧布尔字段。
- [x] 后端、前端和迁移相关自动化检查通过。

## 非目标

- 本票不创建图像块，不向任何 provider 发送图片，也不启用视觉模型。
