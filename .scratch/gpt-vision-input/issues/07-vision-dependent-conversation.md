# 约束视觉依赖会话并恢复兼容模型

## 目标

当前有效分支已经包含图像块时，确保所有后续 Run 只能使用视觉模型，并让模型选择器、会话恢复和编辑解除约束都反映真实上下文。

## 交付范围

1. 从当前未归档用户消息及其当前 Run transcript 派生图片上下文状态，不新增会话级模型或视觉标记。
2. 会话详情和所有成功 mutation 返回权威图片上下文；会话列表不扫描 transcript，也不返回该状态。
3. 四个 Run 创建入口在持有会话锁时按操作后的候选分支校验；视觉依赖分支选择非视觉模型返回 409 与稳定 machine code，且无分支变更。
4. 编辑移除最后一张图片或归档后续图片分支时，可在同一操作选择非视觉模型。
5. 前端禁用不兼容模型；重新打开会话时按最近兼容 Run、兼容全局偏好、目录首个兼容模型的顺序恢复。
6. 没有可用视觉模型时消息变更区只读，但历史查看、附件下载、删除会话和新建对话仍可用。

## 验收

- [x] 视觉依赖状态只由当前有效输入事实决定，归档消息与脱离附件不维持约束。
- [x] 所有不兼容 mutation 都在绑定附件、归档消息和创建 Run 前失败。
- [x] 移除当前分支最后一张图片后可立即切换 DeepSeek，不需要第二次操作。
- [x] 会话恢复优先选择最近兼容模型，原模型下线时按规定回退且不弹额外通知。
- [x] 视觉模型暂时全部不可用时，不会降级到 DeepSeek 或锁死非消息类操作。

## 非目标

- 本票不把视觉功能上线前的附件提示块视为图像块，也不升级旧 transcript。
