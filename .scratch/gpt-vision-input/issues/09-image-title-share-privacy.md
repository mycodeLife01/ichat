# 完成纯图片标题与公开分享隐私边界

## 目标

让纯图片首轮在模型成功回答后仍能获得可识别标题，同时确保视觉能力不会扩大公开分享对私有图片的读取权限。

## 交付范围

1. 自动标题只使用首条用户文字、安全附件元数据和首条成功助手回复，不重新签发或读取图片。
2. 纯图片首轮可结合安全文件名、格式、大小和助手回复生成标题；没有成功助手回复时不生成标题。
3. 公开分享继续只保存附件占位，不包含原件、preview、派生物、URL、图像块快照或匿名下载能力。
4. 含附件会话沿用明确隐私确认，说明助手回复可能包含图片理解结果；助手文本按既有分享语义进入快照。

## 验收

- [x] 成功的纯图片首轮能够生成合理标题，失败或取消的视觉 Run 不会产生暗示已理解图片的标题。
- [x] 标题任务不会访问图片存储、签发读取许可或再次把图像发送给 provider。
- [x] 公开分享页面只显示安全附件占位，匿名调用无法获得 preview、原件或下载许可。
- [x] 助手已经生成的视觉理解文本可按普通助手回复被分享，且隐私确认仍然出现。

## 非目标

- 本票不提供公开图片预览、公开附件下载或图片驱动的第二次标题模型调用。
