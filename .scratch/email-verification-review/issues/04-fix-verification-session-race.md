# 修复验证页 session 恢复竞态并统一英文文案

Type: task

Status: completed

Blocked by: None

## What to build

邮箱验证页在保持公开访问能力的同时，正确等待本地认证状态初始化；已登录用户验证后立即看到刷新后的账户状态，重复打开已使用链接时也能得到友好的成功结果。

## Acceptance criteria

- [x] 未登录用户可以直接打开验证链接并完成验证，不需要建立 session。
- [x] 存在本地 session 时，页面在认证恢复完成后决定是否刷新当前用户，不能使用首次渲染的过期认证状态。
- [x] 验证成功后刷新当前用户；公开端点返回通用失败但当前用户已经验证时，页面显示成功。
- [x] session 恢复与 `/me` 请求的先后顺序不会把已经验证的用户状态回写为未验证。
- [x] 本功能新增的页面文案、错误提示、Toast 和无障碍标签全部使用英文。
- [x] 前端测试覆盖未登录验证、session 恢复中的验证、重复使用链接、用户刷新失败及重发提示。
