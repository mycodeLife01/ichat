# 完成密码重置（消费令牌 + 交叉作废 + 顺带验证）

Type: feature

Status: completed

Blocked by: 02

## What to build

用户点击重置邮件链接后提交新密码完成重置：令牌一次性消费、密码立即生效、旧登录会话全部失效。密码重置流程（A 流程）至此端到端可演示：申请 → 收信 → 重置 → 用新密码登录。

## Acceptance criteria

- [ ] 有效令牌 + 合规新密码（8–128 字符）：重置成功，返回命令状态响应（不自动登录），新密码可登录、旧密码不可。
- [ ] 重置成功吊销该用户全部 refresh token，并作废其 active 的 `password_reset` 与 `account_deletion` 令牌（交叉作废矩阵）。
- [ ] 令牌收件邮箱等于用户当前邮箱时，顺带置邮箱已验证（不变量扩展见 CONTEXT.md「邮箱验证」）。
- [ ] 过期、已使用、已撤销、格式非法的令牌分别得到明确失败（格式非法 422，其余与既有验证链接同样的通用失败语义）。
- [ ] 限流按 verify 模式：IP 限流，Redis 故障 fail-open。
- [ ] 未验证邮箱的用户可正常走完整流程。
- [ ] HTTP API 层测试覆盖上述全部外部行为，含用新旧密码分别登录的端到端断言。
